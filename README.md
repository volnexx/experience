# Опыт

Расширение Obsidian автоматически переносит удаляемые Markdown-заметки в папку `опыт` внутри хранилища. Названия заметок из этой папки образуют указатель: похожие на них словосочетания становятся белыми виртуальными ссылками на архивные заметки.

Папка `опыт` автоматически добавляется в системные исключения Obsidian. Она скрывается из проводника, быстрого перехода, обычного поиска, графа и обратных ссылок. Если включены Virtual Linker и Omnisearch, «Опыт» отдельно применяет их собственные настройки исключения и удаляет уже созданные записи Omnisearch из поискового указателя.

## Поведение

- Обычное удаление Markdown-заметки вне папки `опыт` заменяется переносом в эту папку.
- После успешного переноса закрываются все открытые вкладки этой заметки, включая фоновые вкладки.
- Obsidian не продолжает показывать удалённую заметку уже из папки `опыт`.
- Вложения, другие виды файлов и папки удаляются обычным способом Obsidian.
- Удаление заметки уже внутри `опыт` также проходит обычным способом.
- Папка `опыт` автоматически исключается из обычной навигации и системных средств поиска Obsidian.
- Virtual Linker не использует заметки из `опыт` как цели и не обрабатывает содержимое этой папки.
- Omnisearch включает учёт системных исключений и удаляет из своего указателя как текущие, так и прежние пути архивированных заметок.
- Собственные белые ссылки «Опыта» продолжают работать и открывают точный архивный файл.
- Совпадающие имена не перезаписываются: создаются `Название (1).md`, `Название (2).md` и так далее.
- Для сопоставления сохраняется исходное название до добавления суффикса.
- По умолчанию минимальное сходство равно 90%.
- Регистр букв, различие `ё/е` и вид разделителя между словами не учитываются.
- Щелчок по совпадению открывает соответствующую заметку в папке `опыт`; Ctrl/Cmd + щелчок открывает её в новой вкладке.
- В живом просмотре и режиме чтения совпадения представлены внутренними ссылками Obsidian (`a.internal-link` с `data-href`), поэтому их распознаёт Jump to Link.
- Виртуальные ссылки не изменяют Markdown-текст и не вставляют в него конструкцию `[[...]]`.
- Код, ссылки, адреса, теги и служебные свойства в редакторе не подсвечиваются.

В настройках расширения есть строка состояния изоляции и кнопка `Применить сейчас`. Она полезна, если Virtual Linker или Omnisearch были включены уже после загрузки «Опыта».

## Пример

После удаления заметки `Теория деятельности.md` она окажется здесь:

```text
опыт/Теория деятельности.md
```

Оба словосочетания станут белыми ссылками на удалённую заметку:

```text
теория деятельности
теория деятелности
```

Второе отличается на одну букву, но сохраняет сходство выше 90%.

## Установка

1. Распакуйте папку `experience` в `<хранилище>/.obsidian/plugins/`.
2. Убедитесь, что в папке находятся `main.js`, `manifest.json` и `styles.css`.
3. Перезапустите Obsidian.
4. Включите «Опыт» в разделе сторонних расширений.

## Разработка

```bash
npm install
npm run check
```

Архитектура переноса основана на безопасных приёмах Integrated Archive, визуальная обработка редактора — на подходе Virtual Linker, а устройство кликабельных элементов и совместимость — на способе обнаружения ссылок в Jump to Link. Реализация и нечёткое сопоставление написаны отдельно для этого расширения.
