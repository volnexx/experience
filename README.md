# Опыт

Расширение Obsidian сохраняет Markdown-заметки в скрытом служебном архиве по отдельной команде «Отправить в опыт» и превращает похожие на их названия словосочетания в белые виртуальные ссылки.

## Отправка заметки в «Опыт»

Версия `0.8.0` больше не перехватывает стандартное удаление Obsidian.

В меню заметки под обычным удалением добавляется отдельный пункт в отрицательном цвете текущей темы:

```text
Отправить в опыт
```

У пункта собственный значок: мусорный бак с лицом призрака внутри. Команда доступна через меню файла на настольной и мобильной версиях Obsidian, а также через палитру команд как `Опыт: Отправить текущую заметку в опыт`.

Обычная команда Obsidian `Удалить файл` остаётся обычным удалением и не вызывает «Опыт».

При выборе `Отправить в опыт` расширение:

1. Читает полный текст исходной заметки.
2. Записывает служебный файл с текстом, названием, исходным путём и временем отправки.
3. Читает служебный файл обратно и проверяет точное совпадение всех данных.
4. Только после успешной проверки удаляет исходный `.md` из дерева Obsidian.
5. Закрывает открытые вкладки исходной заметки.

Если запись или проверка не прошла, исходный файл не удаляется. Если удаление исходника не удалось, новая служебная копия откатывается.

Такое разделение важно для синхронизации: удаление, пришедшее с другого устройства, не должно повторно архивироваться принимающим устройством.

## Призрачные заметки удалённых строк

Версия `0.6.0` предоставляет интерфейс для `Line Clone Sync 1.2.0`. Когда последний связанный экземпляр строки полностью удалён, расширение синхронизации передаёт «Опыту» точные строки, исчезнувшие из каждой заметки.

Для каждого исходного пути создаётся одна призрачная заметка с тем же названием. Последующие удаления дописываются в её конец в порядке удаления. Пример:

```text
Мысли.md: еда – купить яблоки
еда.md: купить яблоки
```

После окончательного удаления связи:

```text
Призрак «Мысли»: еда – купить яблоки
Призрак «еда»: купить яблоки
```

Призрачные заметки также хранятся как `.experience` и не попадают в дерево Markdown-файлов. Они не участвуют в белых виртуальных ссылках, чтобы призрак не перехватывал название существующей живой заметки.

Открыть накопленные удалённые строки можно командой `Опыт: Открыть призрачную копию текущей заметки`.

## Настоящая изоляция

Архив находится вне обычного дерева заметок:

```text
.obsidian/experience-archive/
```

Заметки хранятся как служебные файлы с расширением `.experience`, а не `.md`. Поэтому они отсутствуют в `app.vault.getMarkdownFiles()` и `app.vault.getFiles()` и не воспринимаются как заметки Obsidian:

- папка `опыт/` в корне хранилища больше не создаётся;
- проводник, быстрый переход, граф и обратные ссылки не видят архив;
- Omnisearch, Virtual Linker, Dataview и другие обычные расширения не получают архивные записи при обходе файлов хранилища;
- отдельные исключения для каждого расширения больше не нужны.

Как и у любого расширения Obsidian, это не защита от намеренно написанного кода, который напрямую обследует `.obsidian`. Все сторонние расширения работают с правами пользователя.

## Переход с версии 0.3.0

При первом запуске `0.4.0` расширение автоматически:

1. Находит Markdown-заметки в прежней папке `опыт/` или в выбранной ранее папке.
2. По одной записывает и проверяет их в скрытом архиве.
3. Удаляет каждый старый файл только после успешной проверки копии.
4. Удаляет старую папку, только если она стала пустой.
5. Убирает добавленные самим «Опытом» исключения Obsidian и Virtual Linker.
6. Удаляет прежние пути из указателя Omnisearch, если он включён.

Ошибка одного файла не останавливает остальные. Проблемный исходный файл остаётся на месте, а Obsidian показывает уведомление.

## Белые ссылки и просмотр

Версия `0.7.0` использует в редакторе тот же основной приём, что и Virtual Linker: совпадение вне курсора заменяется виджетом с настоящим элементом `<a>`. Поэтому белое словосочетание является не только оформлением текста, а полноценной ссылкой на соответствующую заметку в скрытом архиве.

- По умолчанию минимальное сходство с названием равно 90%.
- Регистр, различие `ё/е` и вид разделителя между словами не учитываются.
- Код, обычные ссылки, адреса, теги и служебные свойства не подсвечиваются.
- Виртуальные ссылки не изменяют Markdown и не вставляют `[[...]]`.
- В тексте, режиме чтения и Markdown-заголовках создаются настоящие внутренние элементы `<a>`, поэтому их видит Jump to Link.
- Пока курсор находится внутри совпадения, исходный Markdown временно показывается как обычный редактируемый белый текст. После выхода курсора он снова становится ссылкой-виджетом.
- Щелчок открывает собственную вкладку чтения «Опыта».
- `Ctrl/Cmd + щелчок` или средняя кнопка мыши открывает архивную заметку в новой вкладке.
- Вкладка читает служебный файл напрямую; архивная заметка не возвращается в дерево Obsidian.

Пример: после отправки в опыт `Теория деятельности.md` оба словосочетания станут белыми ссылками:

```text
теория деятельности
теория деятелности
```

## Настройки и команды

Настраиваются:

- минимальное сходство названия;
- цвет виртуальных ссылок.

Команды:

- `Опыт: Отправить текущую заметку в опыт` — архивирует текущую Markdown-заметку;
- `Опыт: Проверить скрытый архив и завершить перенос` — повторно сканирует служебное хранилище, восстанавливает указатель и завершает безопасную миграцию оставшихся файлов;
- `Опыт: Открыть призрачную копию текущей заметки` — открывает накопленные строки-призраки.

## Установка

1. Распакуйте папку `experience` в `<хранилище>/.obsidian/plugins/`.
2. Убедитесь, что в ней находятся `main.js`, `manifest.json` и `styles.css`.
3. Перезапустите Obsidian.
4. Включите «Опыт» в разделе сторонних расширений.

## Разработка

```bash
npm install
npm run check
```
